# GSLC_Deep_Learning
Deep Learning — Advanced CNNs and Transfer Learning (GSLC)

## Overview

This project explores Convolutional Neural Networks (CNNs) and transfer learning for image classification using a dataset consisting of 37 classes.

The project evaluates the implemented models and compares their performance based on the experiments conducted in the Jupyter notebook.

## Objectives

- Understand CNN architectures for image classification.
- Explore training strategies and transfer learning.
- Evaluate model performance using classification metrics.
- Analyze the impact of model configurations on experimental results.

## Dataset

The project uses an image classification dataset containing 37 classes.

Dataset loading, preprocessing, data splitting, and augmentation follow the implementation in the Jupyter notebook.

The dataset is not included in this repository unless redistribution is permitted by its license.

## Technologies

- Python
- PyTorch
- Torchvision
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/USERNAME/Tugas05-Transfer-Learning.git
cd Tugas05-Transfer-Learning
```

Replace `USERNAME` with your GitHub username.

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Notebook

Open `GSLC_Deep_Learning.ipynb` using Jupyter Notebook or Google Colab.

Follow the notebook cells to load the dataset, train the models, and evaluate the results.

## Evaluation

Model performance is evaluated using the metrics implemented in the notebook. These may include accuracy, F1-score, and training time.

All reported experimental results should be based on actual model outputs.

## Reproducibility

For reproducible results, follow the random seed, dataset split, model configuration, and training parameters specified in the notebook.
